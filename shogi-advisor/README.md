\# 将棋アドバイザー



ブラウザで遊べる将棋ゲームです。



\## 概要



このアプリは、HTML / CSS / JavaScript だけで作られた将棋アドバイザーです。



\- 将棋盤を表示

\- 自分の手を選んで指せる

\- CPUが応手を指す

\- 持ち駒を使える

\- 成りを選択できる

\- 棋譜を表示

\- 局面評価とおすすめ手を表示



\## 起動方法



`index.html` をブラウザで開くと起動します。



\## ファイル構成



\- `index.html` : 画面の骨組み

\- `styles.css` : 見た目

\- `app.js` : 将棋のルール、CPU、評価、操作処理
